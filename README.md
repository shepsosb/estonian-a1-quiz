# Tule ja õpi! — Eesti keele A1 Viktoriin & Mäng 🇪🇪

An interactive Estonian A1 language quiz, grammar critique engine, and board game based on the official **Settle in Estonia** A1 workbook:
> *Tule ja õpi! Eesti keele tööraamat (A1-tase)* by Marju Ilves & Leelo Kingisepp (Kultuuriministeerium, 2021).

## ✨ Features
- **All 23 Workbook Units (`Peatükid 1–23`) + Review (`Kordamine`):** Practice unit-by-unit or in a randomized mix.
- **5 Question Formats:**
  1. **Valikvastus (Multiple Choice):** Includes specific explanations for why each distractor option is incorrect.
  2. **Lünktekst (Fill in the Blank):** Tests Estonian case endings (`-s` vs `-l`, `-st` vs `-lt`, `Kus?` vs `Kuhu?`), verb conjugations, numbers, and time (`veerand`, `pool`, `kolmveerand`).
  3. **Dialoog (Dialogue Completion):** Real *Keeleklikk* dialogues from the workbook.
  4. **Paranda viga! (Fix the Error):** Grammar error spotting and the mixed-up sentences from Unit 10 (`lk 41`).
  5. **Vabavastus (Open-Ended Answers):** Write full Estonian sentences and get automated feedback on structure, case forms, verb negation, and diacritics.
- **Estonian Linguistic Critique Engine:** Identifies specifically what is right and what is wrong (e.g., *I vorm* vs *II vorm* vs *III vorm* confusion, missing `õ, ä, ö, ü` letters, or conjugated verbs after `ei`).
- **Kordamine Board Game (`lk 84–85`):** Roll the dice and advance from `ALGUS` to `LÕPP`.
- **Searchable Grammar Reference (`lk 87–88`):** Instant lookup for the **3 Principal Noun Forms (I, II, III vorm)** and all **14 Estonian Cases**.

## 🚀 Running Locally
No build step or dependencies required—simply open `index.html` in any web browser.
